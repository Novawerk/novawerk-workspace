## 小红书

不放网址，不引导，不招人。旁白是合成人声：发布时把「AI 合成内容」的声明勾上。

**标题（三选一，都不超过 20 字）**

1. 不写代码，也用得上 GitHub
2. 一条视频看懂 GitHub 怎么协作
3. 需求别再丢在聊天记录里了

**正文**

需求在聊天记录里，文件在邮箱里，最新版不知道在谁电脑里。我们做项目时，把这些都放在 GitHub 上。

这条是给不写代码的伙伴看的：GitHub 是什么，三个要认识的词，然后怎么跟你的 coding agent 说一句话，
让它帮你提需求、改文档、传材料。

片里那一步「连上 GitHub」画得很快，实际要先备好几样：agent 装在你自己的电脑上，电脑上装了 GitHub 的
命令行工具并且登录过，你对那个仓库有权限，agent 开在项目的文件夹里。还没有 agent 也没关系，在 GitHub
的网页上自己新建一条 Issue，效果一样。

Novawerk 101 第一条。

## English version (for partners who don't read Chinese)

> A two-minute video: what GitHub is, and how to get your coding agent to open an issue or a pull
> request for you. The film makes "connect GitHub" look like one click; in practice the agent runs
> on your own computer, with GitHub's command-line tool installed and signed in, in the project's
> folder, and you need access to the repository. No agent yet? "New issue" on the GitHub website
> does the same. If any step doesn't work for you, tell me.
