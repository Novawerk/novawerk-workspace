## 小红书

不放网址，不引导，不招人。人声和音乐都是 AI 生成的：发布时把「AI 合成内容」的声明勾上。

**标题（三选一，都不超过 20 字）**

1. 一分钟说唱，听懂 GitHub
2. 不写代码，也用得上 GitHub
3. 需求别再丢在聊天记录里了

**正文**

需求在聊天记录里，文件在邮箱里，最新版不知道在哪。我们做项目时，把这些都放在 GitHub 上。

这条是给不写代码的伙伴看的，一分钟唱完：GitHub 是什么，三个要认识的词，怎么跟 coding agent 说一句话
让它帮你提需求、改东西。

歌里没唱的：提需求时说清想要什么、为什么；agent 要先在你的电脑上配好、登录过 GitHub、有那个仓库的
权限。没有 agent 也行，在 GitHub 网页上自己新建一条 Issue，效果一样。还有，「每一版都存档」也意味着
放进去的东西删了还在历史里，所以密码和隐私一开始就别放。

Novawerk 101 第一条。
