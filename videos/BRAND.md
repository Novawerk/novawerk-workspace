# Novawerk 视频 · 品牌简报

所有视频共用。事实来自 `knowledge/`、`apps/web` 和线上 novawerk.io。每条视频自己的取舍写在
`projects/<项目>/BRIEF.md`。

## Novawerk 是什么

- 一个**开放、非营利的社区**，2025 年成立，正在注册为德国协会（Novawerk e.V. i.G.）。
- 官网标语：*An open workshop for early ideas.*，即"一个给早期想法的开放工作坊"。
- 官网主标题：*We help ideas take their first step.*，即"我们帮想法迈出第一步"。
- 定位是 **workshop（工作坊）**，不是公司、孵化器、加速器、工作室，也不是"平台"。
- 每个人都是 Member。

一句话：**Novawerk 是一个非营利的开放工作坊：你带来想法，我们一起把它做成真的东西。**

## 给谁看

在德国的华人：手里有"要是有这个就好了"的想法，但一个人做不起来的人；以及有技能（开发、设计、
研究、运营）、想做真项目的人。小红书是对外的中文主战场（`knowledge/community/promotion/`）。

## 能讲的事实

- **/submit**：在 novawerk.io/submit 聊你的想法，AI 陪你写成一份 pitch。它用访客的语言回复，
  中文可以；右侧 pitch 面板的字段始终是英文。
- **/join 已关闭**（2026-10）：申请入会的入口关了，/join 跳到 /contribute。视频里不再画 /join，
  不说"申请加入"。
- **/contribute 和任务板**（novawerk.io/tasks）：任何人都能挑任务、提方案、提 PR，合并后得到 Werk
  （致谢，不是钱，也没有等级）。贡献者不是 Member。编程 Agent 可以用令牌和 MCP 参与。代码公开，
  MIT 许可（`Novawerk/novawerk-workspace`）。小红书上可以讲任务板，守住下面的红线。
- **四步**：验证 → 拆解 → 协作 → 真正交付。*We don't make demos.*
- **作品**：YIMA（注重隐私的经期日历）、柏林中餐地图（社区维护的柏林中餐指南），都已上线。
- **团队**（创始人的说法）：资深 AI 工程师、亲切的产品经理、曾经的创业者，还有不眠不休的 Agent。
- **新项目**：聆镜 PSYGYM，给新手心理咨询师练习用的 AI 工具，代码开源。只说它是什么。

## 不能说的

- **不编数字。** 不说"X 位成员""X 个项目""帮助了 X 人"，不写公司名和年限。
- **不夸大。** 不说"改变世界""颠覆""赋能""生态""最好的""第一个"。英文禁词：leverage /
  ecosystem / stakeholders / synergy / disrupt / transform。
- **不说是公司、孵化器、加速器、平台**；不暗示投资、融资、赚钱、包就业、包上线。
- **不提内部信息**：`records/` 里的会议、财务、合作细节一律不出现。
- **不写城市**，除非确认过。
- 口吻是"和你一起"，不是"带你"。
- **小红书：不露网址，不引导。** 画面、字幕、标题、正文、话题里都不放 novawerk.io 或任何网址，
  不写"访问""点链接""私信""评论区见"。2026-10 第一条宣传片因此被限流。其它平台（LinkedIn、
  Instagram）可以放网址。
- **小红书：不能读起来像境外招工。** 2026-10 第二次发布被判"境外招工"，问题出在"欧洲 + 找工程师 /
  成为成员 + 不要报酬"这种组合。2026-10-15 起的规则（创始人原话："其实你只要别说 欧洲+找工程师
  就行，没有那么严格"）：
  - **红线**：不把欧洲 / 德国 / 柏林和"找工程师""岗位""工作""招人"放在一起；不写报酬、股份、薪资、
    token 这类词。
  - **可以**：邀请大家参与开源任务板：挑任务、提方案、提 PR，你的 Agent 也可以来，Werk 是致谢不是钱。
  - 仍然尽量写成"我们做了什么、怎么做的"，#海外华人 #德国华人 不和团队介绍放在一起。

## 视觉：便签堆叠

`kit/` 里的组件就是这套视觉。

| 元素 | 规则 |
|------|------|
| 底 | 白 `#ffffff`，或墨黑 `#0f0f0f` 的面板、整屏 |
| 便签 | 白底、3px 墨黑边框、直角、微微倾斜（`Note`） |
| 强调色 | 白底上用品牌绿 `#1f7a4a`；黑底上用亮绿 `#38e07b`（帖子卡片的绿）。一个画面一个强调色 |
| 字 | 中文 Noto Sans SC 900；英文 Geist；等宽标签 Geist Mono；字标 Cabinet Grotesk 800 |
| 字号 | 主字幕约 100px，副字幕约 48px（1080 宽）；关键词用 `**词**` 标绿 |
| 星标 | `NovaStar`：四角星，外绿内深绿，不加框、不加渐变；可以旋转（14 秒一圈），可以坠落后展开（`starFall`） |
| 彩色 | 只在作品段落用（`kit/shapes.tsx`：作品封面、几何形状） |
| 安全区 | 内容排在 1080×1440 里；9:16 版上下留白，避开小红书底部标题栏 |

动效：淡入上移 220ms、关键词弹一下、硬切踩在节拍上。不用转场模板。

## 声音

配乐用代码合成（`kit/audio/synth.ts`），没有版权问题。画面和音乐共用一个时间轴（项目的
`timeline.ts`），所以切镜、便签落下、打字、星标落地都能逐帧配上音效。发布时也可以在小红书 App
里换成曲库音乐。
