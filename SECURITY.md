# Security

## Report a vulnerability

Email **security@novawerk.io**. Write in English, German or Chinese.

Please don't report it in a GitHub issue, a task on novawerk.io/tasks, a pull request or a
public chat. Those are public.

Tell us:

- what is affected (novawerk.io, admin.novawerk.io, api.novawerk.io, or code in this repo);
- how to reproduce it, step by step;
- what an attacker could do with it.

## What we do

- We reply within 3 working days.
- We keep you posted while we fix it.
- We credit you when the fix is out, if you want that.
- We don't take legal action against good-faith research that follows this page.

## Good faith

- Test only against your own accounts and data. Don't read, change or delete anyone else's.
- Don't run denial-of-service tests, spam or social engineering against us or our members.
- Give us a fair time to fix it before you tell anyone else.

## Scope

In scope: the code in this repo and the services it runs (novawerk.io, admin.novawerk.io,
api.novawerk.io).

Out of scope: third-party services we use (Vercel, GitHub, Google, Resend), reports from
automated scanners without a working example, and missing headers with no impact.

We are a small volunteer team. There is no bug bounty.

Machine-readable contact: [novawerk.io/.well-known/security.txt](https://novawerk.io/.well-known/security.txt).
