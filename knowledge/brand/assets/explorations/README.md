# Brand asset explorations

Design-history drafts kept for reference. **Not canonical.** Use the files
in `../` (one level up) for any real surface.

Snapshot of the 2026-05-14 logo iteration:

| File                                  | What it tried                                                        | Outcome                                              |
|---------------------------------------|----------------------------------------------------------------------|------------------------------------------------------|
| `nova-star-depth.svg`                 | Concentric solid stars, small inner core. Pure-fill black-hole feel. | **Chosen** — promoted to `../nova-star.svg`.         |
| `nova-star-singularity.svg`           | Single star with radial gradient (bright edges → near-black centre). | Rejected — breaks "solid fill only" rule.            |
| `nova-star-accretion.svg`             | Depth core + faint accretion-disc halo.                              | Rejected — halo reads as noise at small sizes.       |
| `nova-star-bw.svg`                    | B&W mark exploration (black outer, white inner cutout).              | **Chosen pattern** — promoted to `../nova-star-bw.svg`. |
| `nova-star-horizontal-fraunces.svg`   | Wordmark in Fraunces (variable serif with SOFT + WONK).              | Rejected — editorial but too soft for "werk".        |
| `nova-star-horizontal-cabinet.svg`    | Wordmark in Cabinet Grotesk 800.                                     | **Chosen** — promoted to `../nova-star-horizontal.svg`. |
| `nova-star-horizontal-bw.svg`         | B&W horizontal lockup (Cabinet + cutout core).                       | **Chosen** — promoted to `../nova-star-horizontal-bw.svg`. |
